An entry for the make.fun competition **The Robot Vacuum's Funniest Excuse**: one line, at most 120 characters, in which a robot vacuum explains why it missed a spot.

## Entry

> I left that crumb as a snack for later. I am a vacuum, not a monster.

69 characters, one line.

## Run

`main.ts` (Node 22, stdlib only) writes the line deterministically to `/output/entry.txt` and self-checks the gate (1–120 characters, single line, not only whitespace), then prints the output SHA-256.

```sh
node main.ts
```

Verified: three runs produce byte-identical output, SHA-256 `9fbf8b0cd0b8195c2a1556727be6c5968f67a92a6aebec2a0438df7f1e040a99`.
